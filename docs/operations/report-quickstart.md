# 보고서 작성 빠른 가이드 (1장)

**대상:** 현장·운영자
**범위:** 장애 조치 보고서 / 일 점검 보고서 작성 → 정제 → 결재 → 인쇄 흐름
**버전:** 2026-04-30 (P1)

---

## 0. 한 눈에 보는 흐름

```
이력 등록 ─────► 보고서 추가 ─► 자동 요약 ─► 인라인 편집 ─► 정제 ─► 결재란 입력 ─► 확정 ─► 인쇄·PDF ─► 수기 사인 ─► 보관
(채팅/현장)    (이력 다중 선택)  (SLM 10~30s)  (양식 5필드)  (✨)    (이름만)      (잠금)   (양식 출력)   (출력물에)
```

---

## 1. 이력 등록 (보고서 작성 전)

이력은 **AI 채팅** 또는 **위기대응 > 작업관리** 에서 평소처럼 등록.

| 채팅 입력 예시 | 자동 분류 |
|---|---|
| "신평 배수지 PLC 고장 기록해줘" | task_category=고장보고, fault_category=고장 |
| "신평 배수지 PLC 일상점검 했어 기록" | task_category=점검, inspection_type=일상 |

채팅이 시설/설비/분류를 자동 감지 → 확인 카드 → [예, 기록] 클릭으로 저장.

---

## 2. 보고서 추가

1. **사이드바**: `보고서` → `장애 조치 보고서` (또는 `일 점검 보고서`)
2. 화면 우측 상단 **[추가]** 버튼
3. **다이얼로그**:
   - 보고일자 선택 (기본: 오늘)
   - 이력 시작일·종료일 (기본: 최근 7일)
   - 후보 목록에서 **체크박스**로 다중 선택
4. **[생성]** 클릭 → SLM 이 항목별 발생/조치를 자동 요약 (대략 10~30초)

---

## 3. 항목별 인라인 편집

상세 페이지에서 항목 카드의 **[편집]** (✎) 버튼:

| 영역 | 입력 |
|---|---|
| 헤더 5필드 | 시설명 / 시설 유형 / 설비명 / 분류 / 점검 sub-type |
| 일시 | 발생 일시·발생 내용 / 조치 일시·조치 내용 |
| 양식 5필드 | 장애 시스템 (체크박스) / 장애 장비 / 장애 현상 / 장애 원인 / 주요 사항 |
| 사진 | **조치 전** 사진 / **조치 후** 사진 — 각각 별도 URL 입력 |

> 💡 **점검 보고서** 는 라벨이 자동으로 바뀜: 발생 → 점검, 장애 시스템 → 점검 시스템

저장은 행별 [💾 저장] 또는 헤더 [저장].

---

## 4. SLM 정제 (선택)

각 항목의 **[✨ 정제]** (Sparkles) 버튼:

1. **확인 다이얼로그** → [정제 실행]
2. **미리보기 다이얼로그**: 좌(현재 본문) / 우(정제 결과) 두 컬럼 비교 (5필드)
3. **[적용 (5개 필드 대체)]** 클릭 시에만 본문 갱신
4. **[취소 (본문 유지)]** 클릭 시 본문 변경 없음

> ⚠️ 편집 모드에서는 [정제] 비활성. **저장 후** 사용.
> ⚠️ LLM 호출 실패 시에도 사용자 입력은 절대 사라지지 않음.

자동 적용:
- `기록해줘`, `했어`, `안 돌아감` 같은 구어체 → 보고서체 (`함.`, `동작 불가`)
- 마침표 단위로 줄바꿈 + 각 문장 앞 `• ` 기호 부여

---

## 5. 결재란 입력

**[결재란 (인쇄 시 표시)]** 카드의 **[편집]** (✎):

| 슬롯 | 입력 |
|---|---|
| 담당 | 담당자 이름 |
| 검토 | 검토자 이름 |
| 승인 | 승인자 이름 |

> 🚫 **전자서명 미사용** — 시스템에는 *이름만* 기록. 결재 도장·사인은 인쇄 후 출력물에 수기로.

---

## 6. 확정 → 인쇄·PDF

1. **[확정]** 버튼 → 확인 다이얼로그 → 잠금 (`status=finalized`)
2. **[인쇄]** 또는 **[PDF]** 버튼 (둘 다 동일 새 창)
3. 새 창에 **장애조치결과보고서** / **일상점검결과보고서** 양식 (Nanum Myeongjo, A4) 자동 인쇄 다이얼로그
4. 다이얼로그에서:
   - **PDF 저장**: 대상/프린터를 "PDF로 저장" 선택 → 파일 저장
   - **종이 인쇄**: 실제 프린터 선택 → 출력
5. **출력물에 결재자가 수기 사인** → 보관

> 💡 수정 필요 시: **[수정 모드 진입]** 으로 잠금 해제 → 편집 후 다시 [확정]

---

## 7. 자주 쓰는 메뉴

| 메뉴 | 용도 |
|---|---|
| 보고서 > 장애 조치 보고서 | 장애 사건 → 보고 |
| 보고서 > 일 점검 보고서 | 일상·정기·특별 점검 결과 보고 |
| 모니터링 > 설비 건강성 > 근본원인 통계 | LLM 분류 결과 + 교체 후보 순위 |
| 관리 > 보고서 카테고리 | 시스템·장비 옵션 추가/수정 (4 type) |

## 8. 트러블슈팅 (FAQ)

**Q. SLM 요약이 빈 칸으로 나와요.**
A. LLM 모델 응답이 잠시 지연됐을 수 있습니다. [✨ 정제] 다시 시도하면 정상 동작 (사용자 입력은 그대로 보존).

**Q. 인쇄했는데 한자 외 글꼴이 깨져요.**
A. 새 창의 폰트(Nanum Myeongjo) 로딩 전 인쇄 다이얼로그가 열렸습니다. 새 창에서 **수동으로 다시 [인쇄]** 누르세요.

**Q. 카테고리 옵션을 추가/숨김하려면?**
A. 사이드바 **관리 > 보고서 카테고리** 에서 추가·라벨 편집·사용 토글·삭제. 4 탭 (장애 시스템 / 장애 장비 / 점검 시스템 / 점검 장비).

**Q. 채팅에서 등록한 사건이 후보 목록에 안 보여요.**
A. 다이얼로그의 **이력 시작일·종료일** 필터를 확인. 기본 최근 7일.

**Q. 다른 사람이 만든 보고서를 수정해야 합니다.**
A. P1 에선 **작성자 본인만** 편집 가능. 관리자에게 요청.
