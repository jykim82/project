# SCADA 알람 임계 보유 현황 조사 — 압력·수위·유량 (2026-07-24)

> **배경:** 성상1(가) 유출압력이 이틀간 계측 상한(10 kgf/㎠)에 포화됐는데
> SCADA 알람이 0건 — 원인 중 하나가 **압력 H/HH 임계 태그 자체의 부재**
> (docs/review-items.md 2026-07-23). 전 사이트 임계 완결성을 전수 조사했다.
> **성격:** 현황 보고 + 구축(셋업) 검증 기준. 임계 태그 신설은 SCADA/PLC
> 측 작업이라 본 시스템 밖 — 여기서는 공백 목록·우선순위·시스템 보완
> 현황을 제공한다.

## 1. 조사 방법

- 계측: `tagtype='Analog Input'` + 종류 키워드(압력/수위/유량), 설정·적산 제외
- 임계 보유: 같은 사이트에 `(HH?|LL?) ?(SET|알람|상태|발생|설정값)` 패턴 태그 존재
  (⚠️ "가압펌프 설정압력" 같은 **제어 목표값은 임계가 아님** — 정규식으로 구분)

```sql
-- 재조사용 (사이트 단위)
WITH meas AS (
    SELECT sitename, facilitytype FROM tb_tag_info
    WHERE tagtype='Analog Input' AND datainfo LIKE '%압력%'
      AND datainfo NOT LIKE '%설정%' AND datainfo NOT LIKE '%SET%'
    GROUP BY 1,2),
lim AS (
    SELECT DISTINCT sitename FROM tb_tag_info
    WHERE datainfo LIKE '%압력%'
      AND datainfo ~ '(HH?|LL?) ?(SET|알람|상태|발생|설정값)')
SELECT m.* FROM meas m LEFT JOIN lim l USING (sitename)
WHERE l.sitename IS NULL;
```

## 2. 결과 요약

| 종류 | 계측 보유 | 임계 미보유 | 판정 |
|---|---|---|---|
| 수위 | 23곳 | 3곳 (가곡·고대리·스모크테스트) | **사실상 완비** — 실시설 2곳만 확인 필요 |
| 압력 | 70곳 | **33곳** | **구조적 공백** — 아래 상세 |
| 유량 | 71곳 | 71곳 (전부) | **설계 특성** — 유량은 고정 임계 부적합, 통계 감시가 표준 (§4) |

## 3. 압력 임계 공백 상세 (33곳)

**패턴: 소블록 말단 압력은 H/L 상태 DI 로 정비돼 있으나, 가압장 계열
(유입/유출/토출/흡입압력)은 임계가 전무** — 성상1 사례의 일반형.

- **가압장 26곳 전원**: 갈산·고대리·기지시·난지·대호·매방리·복운·삼봉·삼화·
  석우·성북·성북1리 제1차·성북1리 제2차·성상1·성상2·성하리·송산2산단공업·
  송산2산단생활·신평공업·신평생활·용연2통·우강·율사·죽동·죽동2·천의리
- **배수지 3곳**: 송악1(생활 유입압력)·합덕(유량계 압력 3점)·행정(토출/흡입)
- **소블록/소소블록 4곳**: 남산11·행정2-3·수청1-1·행정1수청

**SCADA 측 보강 권고 우선순위:**
1. 가압장 **유출/토출압력 H·HH** (과압 = 배관·계기 손상 직결. 성상1 유형)
2. 가압장 **흡입압력 L·LL** (공동현상·흡입 불량)
3. 배수지 3곳·소블록 4곳 (상대적 저위험 — 확인 후 판단)

## 4. 시스템 측 보완 현황 (임계 공백을 메우는 것)

SCADA 임계가 없어도 본 시스템의 통계·품질 감시가 다층으로 커버한다:

| 계층 | 커버 범위 | 갱신 주기 |
|---|---|---|
| 평소 대비 z-score (SCAN_ALL) | 전 Analog — 평소 패턴 이탈 | 5분 캐시 |
| 태그 품질 계층 (포화·고착·무신호) | 전 Analog — **성상1 유형 포화는 여기서 감지** | 1시간 |
| 야간최소유량 CUSUM | 유량 — 누수 의심 | 일 단위 |
| 물수지 검증 (flow_imbalance) | 유량 — 계통 정합 | 캐시 루프 |

→ 유량의 SCADA 임계 전무(71곳)는 공백이 아니라 **통계 감시 소관**으로 판정.
압력·수위 공백도 위 계층이 탐지하나, **즉시성·확실성은 SCADA 임계가 우월**
하므로 §3 우선순위의 현장 보강을 권고.

## 5. 구축(셋업) 검증 활용

신규 고객 구축 시 §1 SQL 을 검수 항목으로 실행 — "계측 있음 + 임계 없음"
목록이 0이 아니면 발주처와 임계 등록 범위를 협의한다.
(`docs/slm-setup-phase-spec.md` 셋업 완결성 검증 항목으로 편입 후보,
`docs/operations/delivery-checklist.md` 검수 절차 연계)
