# GIS 관망도 타임라인 스크러버 사양 v1 (시안 14 적용)

**상태:** Phase 1 구현 완료 (2026-07-19) — `use-gis-timeline.ts` + `GisTimelineScrubber.tsx`
**프로토타입:** `prototype/dynamic-ux/14-timeline-scrubber.html`
**대상 화면:** `/monitoring/gis` (GIS 관망도)

## 1. 목적

지금의 GIS 관망도는 **현재 시점 스냅샷**만 보여준다. 운영자는 "새벽에 무슨
일이 있었나", "알람 발생 전후로 관망 상태가 어떻게 변했나"를 재구성할 때
트렌드·알람 화면을 오가며 머릿속으로 조합해야 한다. 타임라인 스크러버는
**지난 24시간을 지도 위에서 되감기/재생**해 시설 상태 변화와 알람 발생을
공간 맥락에서 한눈에 보게 한다.

- 위기대응 사후 분석(경보 전후 상태), 야간 무인 시간대 리뷰가 1차 유스케이스
- E-025 노스스타(점검→장애→알람)와 동일하게 **사실(DB 시계열)만 재생** —
  보간·추정 값 생성 없음 (Zero-Hallucination)

## 2. UX

지도 하단에 **타임라인 바** 오버레이 (계통도 재생 컨트롤과 동일 어휘):

```
[● 실시간] | [▶︎/⏸] [1×|2×|4×] |──●———————o——o———| 07-19 03:40  [24h]
                         ↑스크럽 핸들   ↑알람 이벤트 도트(심각도 색)
```

- **모드 토글**: `실시간(LIVE)` ↔ `타임라인`. 타임라인 진입 시 LIVE 배지
  대신 재생 시각 표시. 실시간 복귀 버튼 상시 노출
- **스크럽**: 드래그/클릭으로 시점 이동. 재생 시 10분 스텝으로 진행
  (1×=1초당 10분, 2×/4× 배속 — `useChartPlayback` 상수 재사용)
- **알람 이벤트 도트**: 트랙 위에 발생 시각 표시 (경고=red, 주의=amber).
  도트 클릭 = 해당 시점으로 점프
- **시점 t 의 지도 표현** (기존 컴포넌트 재사용, 데이터만 t 기준):
  - 시설 마커 상태색·수위 게이지 → t 시점 값
  - 알람 리플 → t 에 진행중이던 알람만 맥동
  - 팝업 카드 열려 있으면 값·상태 t 기준으로 갱신
- **감쇠 규칙**: 타임라인 모드 동안 30초 자동 갱신·LIVE 폴링 일시 중지
  (복귀 시 재개). reduce-motion 은 재생을 금지하지 않음(스크럽은 사용자
  주도 모션) — 리플 규칙은 기존 예외 그대로

## 3. 데이터

### Phase 1 — 프런트 조합 (신규 API 없음)
- **시설 상태 시계열**: 기존 `POST /trend/data` 재사용. 시설별 대표 태그
  (flow-map/realtime 이 이미 시설↔대표 태그 매핑 보유: 수위/유량/압력)
  를 24h·`max_points=144`(10분 해상도)로 일괄 조회 — 진입 시 1회, 세션 캐시
- **알람 이벤트**: 기존 알람 이력 API (24h 범위) — 트랙 도트 + t 시점
  "진행중" 판정(발생≤t<해제)
- 103시설 × 대표 1태그 × 144pt ≈ 1.5만 값 — 분할 요청(15태그 단위)로 수용
- **데이터 없음 구간**: 마커 회색 처리 (값 생성 금지)

### Phase 2 — 서버 스냅샷 API (성능·기간 확장 시)
- `GET /gis/timeline?from&to&step` → 시설별 {t, value, status, alarms[]}
  사전 집계 응답. 7일+ 기간, 소블록 fill 상태까지 확장할 때 도입

## 4. 구현 형태

- `GisTimelineScrubber.tsx` (지도 하단 오버레이, ~150줄) +
  `use-gis-timeline.ts` (시계열 로드·시점 인덱싱·재생 상태)
- 재생 엔진은 `useChartPlayback` 를 일반화해 재사용 (트렌드와 동일 배속·
  스텝 상수 — 이원화 금지)
- `GisFacilityMarkers`/`WaterLevelGauge`/`GisAlarmRippleLayer` 는 **props 로
  받은 상태만 렌더**하므로 무변경 — 페이지가 t 시점 파생 상태를 주입
- 차트류가 아니므로 E-039 계열 무관하나, 시점 전환 시 마커 상태 변경은
  상태 전이 morph(시안 23, gis-card-badge 0.6s)와 자연 결합

## 5.5 Phase 1 구현 노트 (2026-07-19)

- 진입 시 트랙 끝(최신) 위치, 끝에서 재생 시 처음부터. 타임라인 중
  `useGisFacilities(autoRefresh=false)` 로 실시간 폴링 정지
- 시각 표기는 trend/data 나이브 문자열 그대로 (트렌드 x축과 동일 —
  타임존 해석 이원화 방지). 알람 도트 위치도 같은 축의 사전식 비교 매핑
  (좌표계 불일치 시 도트만 생략되는 안전 실패)
- 스냅샷은 대표 지표 1종만 t 값으로 교체, 현재-시점 전용 정보(알람 배지·
  리플·전망·펌프)는 제거 — Phase 1.5 에서 t 연동 예정
- **타임라인 데이터 패널** (`GisTimelinePanel`): 우측 오버레이 표 —
  시설 | 유량 | 수위 | 압력 (시설이 가진 지표 전체, Δ=직전 10분).
  **정렬은 유형→시설명 고정** — 재생 중 순위가 바뀌면 스크롤로 잡아둔
  현장을 놓친다는 피드백으로 |Δ| 정렬에서 변경. 변화는 셀 하이라이트·
  ▲/▼ 로만 표현. 시설명 검색, 스크러버 표 버튼 토글, 진입 시 자동 오픈.
  **펌프 동작 컬럼은 Phase 2** — 실시간 API 에 펌프 RUN 시계열 태그가
  없어 서버 스냅샷 API(/gis/timeline) 도입 시 제공
