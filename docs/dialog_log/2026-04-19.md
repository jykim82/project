## 비전 에이전트 사진 업로드 404 수정 [E-029]

### 사용자 요청
- "다음할일은??" → "1번부터 진행" (어제 기록한 "내일 할 일" — 비전 에이전트 오류)
- 배경: 채팅에서 사진 업로드하니 "비전 에이전트 오류가 발생했습니다" SSE error

### 진단
- backend(Docker, port 8000), vision_agent(host native, port 8100), Ollama(port 11434) 모두 정상 기동 확인
- 재현 테스트 (curl `/ask/multimodal/stream` + 이미지) → SSE event `error` + 404
- 근본 원인 2건:
  1. vision_proxy가 **컨테이너 내부 절대경로**를 `image_url`로 vision_agent(호스트)에 전달 → 호스트 FS에 해당 경로 없음 → `_load_image_base64` HTTPException(404)
  2. docker-compose.dev.yml backend 서비스에 `chat_attachments`/`facility` 호스트 바인드 마운트 자체가 없어 파일이 컨테이너 레이어에만 존재

### 변경 요지
- `slm/endpoints/vision_proxy.py` — `_save_upload` `(path, url)` 튜플 반환, vision_agent엔 URL 형식 `/api/files/chat_attachments/<name>` 만 전달 (vision_session 저장·`vision_advice.image_url` 도 URL로 통일)
- `slm/vision_agent.py` — `CHAT_ATTACHMENT_DIR` env 상수 추가, `_resolve_image_path`에 `/api/files/chat_attachments/` prefix 핸들러, 기본 경로 1레벨 오차 수정
- `web/docker-compose.dev.yml` backend — volumes `./files:/data/files` 추가, env `CHAT_ATTACHMENT_DIR=/data/files/chat_attachments`, `FACILITY_FILE_BASE_DIR=/data/files/facility`
- 호스트 `/Users/jykim/web/files/chat_attachments` 디렉터리 신규 생성

### 검증
- 실제 PNG(`anim-t1.png`, 170KB)로 `/ask/multimodal/stream` 재호출 → `vision_session_id=36`, VLM 46.9s 응답 정상 반환
- 호스트 `web/files/chat_attachments/` 와 컨테이너 `/data/files/chat_attachments/` 에서 동일 파일 가시

- web@704d699 — docker-compose + docs
