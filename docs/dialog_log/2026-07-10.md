# 2026-07-10 세션 대화 로그

## 채팅 인텐트 분류 — 짧은 follow-up 지표 상속 오답 수정

### 사용자 요청
- "오늘 전체 배수지 유출량은?" 직후 "배수지 총유량은?" 질문의 답이
  **앞선 질의 답변으로 대체**되어 나온다. 분류가 잘되는지 확인 요청.

### 원인
- `session_manager.is_short_followup()` 의 `len(q) < 10` 규칙이
  10자 미만 질문을 **무조건 직전 인텐트로 상속**.
- "배수지 총유량은?"(9자)이 직전 `TODAY_OUTFLOW_ALL_STATUS`(유출량)를
  상속 → 실제 의도 `TODAY_FLOW_ACCUMULATION`(총유량) 대신 유출량 답 재사용.
- 두 인텐트는 example3.json 에 각각 정확히 정의됨 → **분류기 자체는 정상**,
  세션 상태 상속이 원인.

### 조치
- `is_short_followup()` 에 `_standalone_metric_nouns` 가드 추가.
  질문이 유량/유출량/총유량/수위/압력/공급량/적산/순시 등 **지표를 스스로
  명시**하면 (a)<10자·(b)표지+<20자 밴드 모두 상속 거부 → 재분류.
- 지표 없는 조각("오늘 것도", "가압장은?", "그럼 어제 것도?")만 기존대로 상속.
- 단위 검증 8/8 통과. 백엔드 재기동으로 반영.
- 사양: `docs/review-items.md §멀티턴 (a-fix)` 갱신.
