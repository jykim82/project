## 교차 검증 질의 분류 ~10초 지연 해결 (SSE 신뢰성 문의)
- 문의: "교차 검증 결과" 질의의 분류가 오래 걸리는 것처럼 보이는데 SSE 를 믿어도
  되나? 나머지 스텝은 순식간에 지나감.
- 실측(SSE 타임라인): classify@0.02s → **extract@9.8~10.7s** → query/render 즉시.
  즉 전체 ~10초가 분류 단계 소모. SSE 는 정확(진짜 분류가 느림).
- 원인: `intent_classifier._classify_category`(Stage1)의 `common_keywords` 에
  "교차 검증" 계열이 없어 keyword 단축 실패 → **SLM(gemma4:26b) 카테고리 분류
  폴백 ~10초**. 임베딩은 ~90ms 로 무관. 인텐트 단계(Stage2)엔 교차검증 키워드가
  있어 조회는 즉시였음(카테고리·인텐트 키워드 집합 불일치).
- 해결: `common_keywords` 에 교차 검증/교차검증/시설간 불일치/유량 불일치/흐름
  불일치/정합성 추가 → **분류 ~10초 → 0.1~0.4초**. intent=ANOMALY_CROSS_FACILITY
  결과 동일 검증.
- 일반 원칙(사양 기록): 새 인텐트 keyword 추가 시 Stage1(카테고리)+Stage2(인텐트)
  키워드를 함께 갱신해야 SLM 폴백 지연이 없음.

## 유량·수압 '흐르는 느낌' 애니메이션 — DDNS/외부 접속 시 정지 원인·해결

- 원인 파악: localhost·DDNS 모두 같은 prod 빌드(Caddy) 확인(빌드 산출물 CSS에

  전혀 없음. 유일한 정지 요인 = 전역 reduced-motion freeze(*{iteration-count:1}) 인데
  예외가 .slm-live-* 만 있고 .metric-* 은 없음. 즉 접속 기기의 '동작 줄이기'
  (모바일 기본 on·저전력)가 흐름 애니메이션을 동결. (media query 라 URL 무관 —
  외부/DDNS 접속 기기 쪽 설정 차이)
- 해결: globals.css 에 흐름 계열(metric-dash-flow/level-shine/level-glow/droplet/
  pressure-wave/pressure-pipe) reduce-motion 예외 추가(물결게이지 .slm-wl-*·스피너
  .slm-live-* 와 동일 취지). animation-duration·iteration-count 만 복원(name·delay
  불변 → droplet 스태거 보존). 깜빡임 계열(status-dot/ring-pulse/end-dot)은 reduce
  존중해 제외.
- 검증(Playwright emulateMedia reduce): dash/droplet iteration-count 1→infinite 복원,
  status-dot 은 1 유지(의도대로).

  급락하는 비현실적 직선. 기존 물리 클램프(하한 0)로는 안 잡힘.
- 원인: _linear_forecast 가 최근 24샘플 선형회귀 slope 를 적합도 무시하고 그대로
  24h 외삽 → 진동 신호의 우연한 하강 기울기가 급락선으로 증폭.
- 해결: 회귀 R² 계산 → slope_eff = slope×R² 감쇠(진동=평탄 수렴, 뚜렷한 추세=반영).
  외삽 기준을 마지막 실측값으로 이동(이음새 자연). 반환 slope 도 감쇠값이라 status
  일관. 검증: 4개 수위 tag forecast 3.24~3.29 밴드 내 평탄(기존 2.1 급락 제거).
- 후속: R² 감쇠만으론 진동 신호가 순간 기울기 방향을 여전히 따라감(실측 확인 —
  A구설1지 오실레이션인데 하강 구간이라 forecast 하강). → R² 로 [추세 외삽]과
  [최근 평균 회귀]를 블렌딩: forecast=last_y+(slope·R²)·dh+(1-R²)(mean-last_y)(1-φ^i).
  진동=평균 수렴, 실추세=반영. 임계 도달 시점은 곡선 시리즈에서 직접 스캔(선형 slope
  아님). 검증: A구설1지 밴드 내 3.13→2.80, 신설5지 만수위 4.20→3.90 완화(12h→20h).
  (참고: "신설 1지"는 태그 오독 — 신설=5지·구설=1/2지. 행정 배수지 시설 수위 태그 맞음.)
