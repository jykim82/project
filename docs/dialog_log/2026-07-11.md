## 계통도(용수공급) 배수지 클릭 부드러운 확대 복원
- 증상: 계통도(MapLibre) 노드 클릭 시 부드러운 확대(flyTo)가 사라짐.
- 원인: MapLibre 는 `prefers-reduced-motion`(동작 줄이기) 시 flyTo 애니메이션을
  건너뛰고 즉시 점프 → "부드러움 없어짐"으로 인지. (흐름도는 custom rAF 라 무영향)
- 조치: `FlowDiagramMap.tsx` handleNodeClick 을 `getMap().flyTo({ essential: true,
  zoom: max(getZoom()+1,15), duration: 800 })` 로 변경. essential 로 reduce 예외,
  zoom+1 로 항상 확대 체감. 검증: 클릭 후 줌 Lv 15 확대·노드 포커스.

## 교차 검증 결과 — 카드 디자인 적용 + 진행 표시 상시화
- 요청: "교차 검증 결과" 응답을 목업(카드형)대로 개선. 대시보드 KPI(교차검증 이상)
  → AI 분석 팝업이 "멈추는 듯 보이다 결과가 나옴", 카드 디자인 미적용.
- 백엔드: `response_builder.py` ANOMALY_CROSS_FACILITY 분기에서 구조화 데이터
  (`cross_facility_mismatches`, `cross_anomaly_count`)를 top-level 응답으로 노출
  (기존 flat 텍스트 detail 은 프런트에서 억제). `build_success_response` 가
  `processed_data.get(...)` 를 kwarg 로 전달하는 기존 경로 재사용.
- 프런트 신규: `CrossValidationList.tsx` — 상류→하류 흐름(✕▶) + 가동률 비교 바
  (상류/하류 active_pct) + 진단 배지(공급 단절/인과 급락/방향 역전/가동률) +
  핵심 지표(상류 평균→0 등) + 판정 근거 칩. 다크/라이트 공용.
- 배선: `types/chat.ts`(bot.cross_facility_mismatches) → `chat-response-mapper.ts`
  → `ChatMessageArea` → `BotMessage`(intent=ANOMALY_CROSS_FACILITY 시 카드 렌더 +
  flat detail 억제). `AnomalyScanView` 의 기존 CrossFacilitySummary 도 신규
  컴포넌트로 통일(중복 제거).
- 진행 표시: `.slm-live-spin`/`.slm-live-pulse`(reduced-motion 전역 freeze 예외)를
  ChatMessageArea 컴포넌트-스코프 `<style jsx>` 에서 `globals.css` 전역으로 승격.
  `QuickAnalysisDialog` 의 로딩 스피너/스텝퍼에 적용 + 로딩 중 진행 스텝퍼 상시
  표시 → 병목 조회(교차검증 수초) 중에도 멈춘 것으로 오인되지 않음.
  겸사겸사 QuickAnalysisDialog 참고(ReferenceBlock) 렌더 잠재 버그 수정.
- 검증(Playwright, prod 빌드): /chat + 대시보드 KPI 팝업 모두 카드 렌더 확인,
  전역 `.slm-live-spin` 규칙 reduced-motion 에서 `infinite` 확인.
