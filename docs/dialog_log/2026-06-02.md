## 진단

기존 `compute_causal_hint` 가 sources 가 있으면 무조건 `chat_intent =
FACILITY_ALARM_CAUSE_DIAGNOSIS_RANK` 부여 → 프런트 CausalHintCard 가 항상
"→ 상세 원인 진단 →" 버튼 표시. 알람이 적은 시설은 클릭해도 "조회된 데이터
없음" 응답 → 사용자 혼선.

## 조치

### 백엔드 (`slm/trend_comparison.py`)
- chat_intent 신뢰도 보장 로직 추가:
  - alarm kind source 의 detail 에서 `(\d+)건` 추출 → **≥10건** 인 경우만
    `chat_intent` 부여
  - flow_change 만 있는 경우 → chat_intent omit (전용 인텐트 미존재)

### 프런트 (`ComparisonOverlayUI.tsx`)
- `hasDiagnoseLink = !!hint.chat_intent`
- handleClick: hasDiagnoseLink 가 false 면 무동작 (안전망)
- 버튼 자체를 `{hasDiagnoseLink && (...)}` 조건부 렌더
