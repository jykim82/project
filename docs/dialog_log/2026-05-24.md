## 3. 평소 대비 overlay 가시성 강화 (5/24)

**원인 진단**:
1. stack 음영 로직 버그 — 변수명 혼동으로 lower~upper 영역이 잘못 계산
   - `b.band_lower.map((upper, i) => { const u = b.band_upper[i]; return u - upper })` 가
     실제로는 `(band_upper - band_lower)` 가 아니라 잘못된 stack 값을 만들고 있었음
2. 음영 opacity 0.18 — 다크모드에서 거의 안 보임
3. baseline dashed line 1.5px — 가는 편
4. z-order 메인 line 아래 (z: 2) — 비교 인지 어려움

**개선** (`PlotChart.tsx`):
- stack 로직 올바르게 — `band_lower` 가 base, `band_upper - band_lower` 가 음영
- 음영 opacity **0.18 → 0.32**
- baseline line **1.5px → 2.5px**, 색상 `#10b981 → #34d399` (더 밝은 emerald) + shadowBlur
- z-order **2 → 5** (메인 위에 떠서 비교 직관)
- forecast 도 동일 강화 (2.5px + shadow + bold threshold 라벨)

**검증** (`tmp/trend-overlay-enhanced-jukdong.png`):
- 녹색 ±2σ 정상 범위 음영 차트 전체에 명확
- 녹색 dashed baseline 또렷
- 주황 dashed forecast 우측 외삽 명확
- 빨간 "운영 한계 (HH)" 라벨 bold

## 7. 다중 tag·이종 trend 처리 (§4.5 + §7.7 신설)

### 분류 결과
| 케이스 | 처리 |
|--------|------|
| 유량순시 + 적산 | 적산 자동 skip → 순시만 비교 표시 |
| 수위 + 유량 | 워스트 status tag 자동 선택 + dropdown 으로 전환 |
| 동종 다중 (수위 3개) | 워스트 자동 + dropdown |
| 디지털 + 아날로그 | 디지털 자동 skip |

### 백엔드 (`slm/trend_comparison.py`)
- `_is_skip_target(conn, tagsn)` 신규 — 적산/디지털/누적 단위 판별
- compute_comparison 진입부에 skip 가드 → 적산은 응답에서 omit
- 검증: 죽동 3태그 호출 → 적산만 빠지고 2개 반환 ✓

### 프런트 (`ComparisonOverlayUI` + `TrendChart`)
- `selectWorstTag(comparisonMap, tagOrder)` — alert > warning > normal 우선
- `ComparisonTagSelector` 신규 — eligible tag 2개+ 일 때만 dropdown 노출
- `ComparisonHeader` 에 selector prop 추가 (옵션 — 단일 tag 시 hidden)
- TrendChart: activeTagId state + localStorage `trend-overlay-active-tag-{chartKey}`
  영속 (사용자 선택 기억)
- explain 호출도 activeTagId 기준 — xAI 컨텍스트도 활성 tag 따라감
- PlotChart 는 단일 tag 응답 패턴이라 변경 없음 (필요 시 확장)

### 적용 범위
TrendChart 한 곳 수정 → 트렌드 메뉴 / 모니터링 (배수지·가압장·블록) / GIS 팝업
