## 요청 8 — 분류별 경보 현황 레이아웃 개편
**사용자:** Claude 디자인 "SLM Alert Analytics" 참조 URL + 스크린샷 공유 → "경보관리의 분류별 경보 현황을 오른쪽과 같이 개편"

**기존:** 도넛 차트 + 범례 + 중앙 총건수 (정보 밀도 낮음)

- 상단: 타이틀 + [추천] 뱃지 + 시간 범위 탭 (1h/6h/오늘/주)
- 하단 KPI 4셀: 총 경보 / 긴급 / 미확인 / 해결 (각 %) — tone별 컬러
- 카테고리 고유 색 매핑: 수위(blue) 네트워크(amber) UPS(emerald) 압력(violet) 정보(pink) 유량(cyan) 교차검증(rose) 밸브/전원 등
- `reports` prop 추가 → 미확인/해결 KPI 계산
- `hourlyByCategory` / `yesterdayDelta` / `onRangeChange`는 선택 prop (백엔드 확장 전 graceful degrade)

**사양:** `docs/alarm-category-summary-spec.md` 신규
