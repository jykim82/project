# 2026-07-01 세션 로그

## GIS 시설 메뉴 고도화 — 1차 마지막 + 2차

### 사용자 요청
- "마지막 항목까지 진행하고 2차로 넘어가"

### 1차 마지막 — 시설 일반현황 인스펙터 편집
- GisDetailPanel 헤더 "시설 정보" 버튼 → facilitytype 별 시설 일반현황 수정
  다이얼로그(배수지→Reservoir/가압장→Booster/감압→Pressure/소블록·소소블록→Block,
  모두 editSitename 으로 내부 조회). slm-dashboard `2fb4ba5`.
- 검증: 행정배수지 "시설 정보" → "행정 수정" 폼 실측 prefill(설치 2009·급수구역·주소·
  용량 6400㎥·존별 면적/높이).

### 2차 — 설비 고장이력 + 교체주기 (인스펙터 통합)
- 신규 GisEquipmentRow(SRP 분리): 잔존수명 배지(교체권장/임박/정상) + 확장 시
  설비유형 고장이력 타임라인. 기존 엔드포인트(equipment-health/lifespan,
  alarm-fault-correlation/equipment-timeline) 재사용 — 백엔드 무변경. `4bc68f6`.
- 검증: 행정 PLC "최근 1년 알람0/고장3"; 갈산 가압펌프 임시 설치일(2010) 주입 →
  "교체권장 16/12년" 배지 확인 후 데이터 원복. tsc 신규 에러 0.
- 잔존수명 배지는 commissioned_at·카테고리 입력 시 표시(현재 295개 전부 no_data
  → 데이터 보강 의존, 코드는 검증 완료). 사양 §6/§10/§11 갱신.

### 작업 상태
- 1차 완성(설비 CRUD·제원 필드·시설 편집), 2차 완료(고장이력·교체주기). 잔여는
  데이터 보강(설치일자·카테고리 시드) + 권한/감사 강화 + MTBF/월별 탭.
