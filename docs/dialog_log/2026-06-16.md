## DI 현재값 라벨링 (태그 모니터링 Phase 4) — 극성 지정 가능

### 사용자 요청
- "di 현재값 라벨링은 0정상 1 고장일때도 있지만 반대 일수도 있어 지정할수 있으면
  좋은데 이부분은 먼저 설계를 진행해줘" → 설계 제시 후 "승인. 진행해줘."
- 핵심: DI 0/1 의미 라벨 표시 + **극성(어느 값이 이상인지) 태그별 지정**.

### 설계 결정 (승인됨)
- (a) 상태 DI 기본 라벨 OFF/ON, (b) 우클릭 인라인 다이얼로그, (c) v1 은
  태그 단위 오버라이드만.
- 3-요소 모델 `(label_0, label_1, abnormal_value)`, `abnormal_value ∈ {0,1,null}`.
- 기본 규칙(zero-config)으로 1,755 DI 태그 무설정 동작 + **예외 전용** 오버라이드
  테이블(행 있는 태그만). 삭제 시 기본 규칙 복귀(무손실 롤백).
