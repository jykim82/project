## 단위 무관 정확도% — 실데이터 기준 정확도 인식 개선

### 사용자 요청
- "실제 시설별 지표, 실제 데이터 기준 정확도 등을 인식하기 편하게 구성해줘".

### 핵심 설계
- 절대 MAE 는 단위·스케일 혼재(유량 LPS 수백 vs 수위 m 한자리)라 시설 간
  "얼마나 정확한지" 직관 불가. **단위 무관 정확도% = 100×(1−MAE/y_scale)**
  ([0,100] 클램프) 도입. y_scale = holdout 실제값 평균 절대크기.
- 정확도%를 그룹/최악 태그의 **헤드라인 컬럼**(색상 바)으로 승격 + **전체
  정확도% KPI**. 그룹은 정확도 낮은 순 정렬로 진짜 부진 시설 노출
  (예: 죽동2 가압장 MAE 1.11 작아도 정확도 26.7%).

### 변경 파일
- 백엔드 `slm/trend_baseline.py`(tag_metrics·`_persist_metrics` 에 y_scale),
  `slm/endpoints/baseline_eval.py`(`_ACC_SQL` 헬퍼 + worst/groups/전체 정확도).

## 저신호 가드 + 시설 진단·권장 조치

### 사용자 요청
- "추천안으로 적용. 그리고 이러한 시설별 상황에서 해야할 부분을 어떻게 판단하면
  좋을지 UI에 표현할 수 있나?" + "어떤 조치를 해야하는지도 판단해줄 수 있나?"

### 배경
- 죽동2 가압장 등 일부 시설이 정확도 26.7% 처럼 낮게 보였으나, 실측값이 거의 0
  (센서 정지/대기)인 태그라 MAE/y_scale 비율이 폭발해 정확도%가 0%로 왜곡된 것.
  "못 맞춤"이 아니라 "맞출 신호가 없음" → 평균을 끌어내려 시설 평가 오도.

### 핵심 설계
- **저신호 가드**: y_scale 이 종류별 바닥값 미만이면 `low_signal=TRUE`. (a) 정확도%
  대신 '저신호' 배지, (b) 그룹·전체 정확도 평균에서 FILTER 제외, (c) 그룹 행에
  `(N 저신호 제외)` 부기. 바닥값은 종류별 분리(MAE≥y_scale 규칙은 큰 신호 태그의
  진짜 부정확을 가려 채택 안 함).
- **시설 진단**: 그룹 드릴다운 상단 `DiagnosisBox` — 태그 구성을 규칙으로 분석해
  종합 판정(데이터 누적 대기 / 조치 권장 / 판단 보류 / 정상) + 권장 조치 불릿.

### 변경 파일
- 백엔드 `endpoints/baseline_eval.py` — `LOW_SIGNAL_FLOOR`(flow 2.0/pressure 0.5/
  level 0.2/quality 0.05/other 0.5, default 1.0) + `_LOWSIG_SQL` 헬퍼. worst·
  group-tags 에 `low_signal`, by_kind/by_site/overall 정확도 `FILTER (WHERE NOT
  low_signal)` + `n_low_signal`/`overall_low_signal` COUNT.
- 프론트 `lib/api/baseline-eval-api.ts` — low_signal/n_low_signal/overall_low_signal 타입.
- 프론트 `app/(dashboard)/admin/baseline-eval/page.tsx` — `AccuracyCell` 저신호
  배지(tooltip), 그룹 행 저신호 부기, `diagnoseFacility`+`DiagnosisBox`(드릴다운
  상단), GLOSSARY 12종(저신호·진단·권장 조치 추가).
- 문서 `docs/trend-baseline-gbt-spec.md` §6.3/§9.

### 검증
- API: 전체 정확도 86.6%→86.9%(122 저신호 제외), 유량 그룹 60.4%(48 제외).
  worst 유량(y_scale 200~826) 전부 low_signal=False·낮은 정확도 유지, 죽동2 미세
  y_scale(0.078~1.45) 3태그 low_signal=True·압력계1(10.07) active 87% 유지로
  저신호↔진짜 부진 구분 확인.
- Playwright: 고대리 배수지·소난지도 소블록 등 전저신호 시설 배지, 그룹 행
  "(N 저신호 제외)" 부기, 죽동2 가압장 펼침 → DiagnosisBox "데이터 누적 대기"
  + 불릿("센서 3개 저신호…", "데이터 부족…") 렌더 확인. tsc 신규 에러 0.

## baseline-eval 평가 화면 직관성 강화 (운영자용)

### 사용자 요청
