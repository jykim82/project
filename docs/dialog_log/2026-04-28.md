## 종합 테스트 (단위 12 + E2E 5 = 14/14 PASS)

**단위 (`light_format_report_text`)**
1. 명령형 제거 (`기록해줘` 끝부분 제거)
2. 종결어미 — `했어`→`함.`, `났네`→`발생함.`, `이야`→`임.`
3. 구어체 — `안 돌아감`→`동작 불가.`, `안 돼서`→`동작하지 않아`
4. 기존 기호 유지 (`1)` `2)` 등)
5. 다중 공백 단일화
6. 3문장 분리 (마침표 단위)
7. LTE 통신이상 시나리오 보존 + 줄바꿈
8. 빈 문자열 / 마침표 없는 단일 문장

**E2E**
9. `dry_run=true` — DB 미반영 + `current`/`refined` 응답 비교
10. `PATCH /reports/items/{id}` 로 정제 결과 적용 → 응답에 `• ` 시작
11. DB `tb_report_item.occurred_text` 직접 SELECT — 갱신 확인
12. 화면 (상세 페이지) 에 `• ` + 줄바꿈 표시 — `tmp/screenshots/test-applied-bullet-format.png`
13. **신규 보고서 #9 생성** 시 `summarize_task` 가 처음부터 `• ` 적용
14. 미리보기 → 적용 안 함 시 DB 본문 유지 + **점검 보고서 #9** 항목도
    `• 신평 배수지 PLC 일상점검 함.` 정제 적용
