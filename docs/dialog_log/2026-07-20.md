## 연결음 + 외부망 통화 옵션 (coturn) + 부하 확인

- 통화 연결음: WebAudio 톤 (발신 425Hz 링백 / 수신 740+880Hz 벨) +
  끄기 토글 (수신 모달·발신 바, localStorage)
- 서버 부하 실측: 폴링 전체 ~1.2 req/s (2 브라우저), backend CPU 17%/1코어,
  DB 0.03% — 여유. 사용자 승인 후 coturn 진행
- coturn: compose profile "turn" + /call/turn-credentials (시간제한 HMAC,
  TURN_ENABLED 옵션 — 납품 기본 off) + 프런트 iceServers 주입.
  로컬 릴레이 할당 검증 완료. 실 LTE 통화는 공유기 UDP 포트포워딩 필요
