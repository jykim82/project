### ⓪ tb_tag_raw_data 압축 (Migration 0128)
- 조사 시점 **447M 행 / 120 GB** (데이터 33 + 인덱스 88), 압축·보존정책 없음
- `segmentby=tagsn, orderby=logtime DESC` — 앱 조회가 전부 `tagsn = ANY(...)`
- **결과: 97 GB → 492 MB (201.7×)**, 전체 120 GB → 28 GB (21/26 청크)
- 무결성: 압축 전 5분 cagg 와 대조 **2,700 태그 전부 count·min·max 일치**
  · 중간 불일치는 청크 경계가 UTC 인데 KST 로 잘라 9시간 어긋난 내 실수
- 조회 기간별 (사용자 확인 요청 항목):

  | 기간 | 전(cold) | 후(cold) | 전(warm) | 후(warm) |
  |---|---:|---:|---:|---:|
  | 24시간 | 23 ms | 22 ms | 9.6 ms | 11.4 ms |
  | 7일 | 116 ms | 133 ms | 37.7 ms | 42.6 ms |
  | 1개월 | 3,936 ms | 2,579 ms | 133 ms | 99 ms |
  | **1년** | **25,245 ms** | **1,999 ms** | 1,027 ms | **278 ms** |

  24시간·7일 무변화는 의도 — `compress_after=14일` 밖이라 비압축 유지
- **락 주의**: `compress_chunk` 는 AccessExclusiveLock. 검증 중 Node-RED 알람
  INSERT 가 9분 차단됨 → 정책 job 새벽 3시 고정 + `lock_timeout` 로 대기 포기.
  최초 일괄 압축은 마이그레이션에서 빼고 수동 절차로 분리
