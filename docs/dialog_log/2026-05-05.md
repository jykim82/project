## 추가 — 흐름 방향 화살표 + interpolate 폴백
사용자: "물의 흐름을 화살표로 표기할수 있나? 널찍하게"

### interpolate 폴백 (콘솔 에러 fix)
- 모든 노드 압력 50.0m 동일 → MapLibre `interpolate` strictly ascending 위배 에러
- pSpread < 1e-6 (압력 분포 없음) → `circle-color` 단색 hsl(160) 청록 폴백
- fmaxRaw < 1e-6 (유량 분포 없음) → `line-color` 회색 + `line-width` 1.5px 고정

### 흐름 방향 화살표
- SDF 화살표 SVG → Canvas → `addImage(..., {sdf:true})` → `icon-color` paint 으로 색상 분기
- 신규 layer `epanet-sim-flow-arrow` (symbol layer, source = SRC_PIPES)
  · `symbol-placement: line`
  · `symbol-spacing` 줌별 보간: zoom 10 → 200px, 14 → 400px, 18 → 600px (널찍하게)
  · `icon-rotate`: flow_lps < 0 → 180° (역류 = 반대 방향)
  · `icon-color`: 정류 청록 / 역류 주황 / 거의 0 회색 (paint case 표현식, fUniform 시 단색)
  · `icon-size` 줌별: 0.4 ~ 1.2
