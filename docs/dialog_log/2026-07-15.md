### 1단계 변경 (`slm`)
- `example3.json`: 인텐트 정의에 선택 메타 필드 도입
  - `dynamic_sql: true` — 16개 마킹 (기존 하드코딩 12 + _SUPPLY 4)
  - `classify_keywords.stage1` — 6그룹 27키워드 (교차검증/설비장애/센서스캔/
    물수지/누수/표준편차 — 회귀 이력으로 하드코딩에 추가됐던 것들을 인텐트 정의로)
- `intent_matching.py`: `dynamic_sql_intents()` / `stage1_keywords_from_definitions()` 파생 함수
- `ai_server.py`: SSE 인라인 하드코딩 세트 제거 → 모듈 로드 시 파생 1회
- `intent_classifier.py`: 하드코딩 리스트에 인텐트 무관 공통 신호만 남기고
  파생 키워드 합산 (lazy import + 캐시)

### 검증
- 파생 dynamic 세트 == 기존 하드코딩+_SUPPLY (16개 완전 일치)
- 파생 stage1 ⊇ 이관 27키워드 (누락 0)
- 스모크 16/16 통과 + 파생 키워드 실매칭 로그 확인 ('교차 검증'/'물 수지'/'설비 장애')
