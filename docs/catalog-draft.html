Overview

제품 개요 — Why SLM

상수도 운영의 3가지 현실

① 데이터는 많지만 판단은 어렵다
SCADA 태그 수천 개, 알람 수백 건. 무엇이 진짜 이상인지 걸러주는 체계가 없다.
② 현장과 관제가 분리되어 있다
알람은 관제실에, 조치 기록은 수첩에. 오탐·미검지 분석이 불가능하다.
③ 폐쇄망이라 최신 AI를 못 쓴다
클라우드 LLM 기반 솔루션은 상수도 보안 환경에 반입 자체가 불가하다.

SLM의 답 — 자산 전 수명주기(Lifecycle)를 하나의 시스템으로

축제공 가치
감시실시간 계통도 · GIS 관망도 · 트렌드로 설비 상태 완전 가시화
알람분류별 경보 + 오탐·미검지 분석 + 현장 조치 통합
장비 고장 관리AI 채팅 진단 + 고장 케이스 DB + 조치 이력·교체 후보
관망 구축·조회시설·설비·태그·매뉴얼·GIS를 일관된 모델로 구성
핵심 한 줄 — 모든 AI가 로컬 서버에서 구동됩니다. 외부 인터넷·클라우드 의존이 0인, 폐쇄망 완결형 솔루션입니다. 지도 타일·AI 모델·폰트까지 오프라인 번들로 반입합니다.

3자연어 장애·조치 기록

현장 작업자가 대화하듯 기록합니다. 시설·설비·태그가 자동 매칭되고, 조치 완료까지 채팅으로 마감합니다. 모바일 현장 모드로 이동 중에도 알람 대응·일상 점검이 가능합니다.
