설치 후 관리 화면 토글로 모듈 관리 — 등급 변경 시 재설치 불필요

기술 스택 요약

  • 웹 기반 — 브라우저만으로 접속, 모바일 반응형
  • PostgreSQL + TimescaleDB 시계열 엔진
  • 로컬 AI (LLM·비전·음성인식) — GPU 서버 1대로 구동
  • Docker 기반 설치 · region 멀티테넌시로 고객별 격리
  • 무중단 업그레이드 경로 + 자동 모델 재학습 내장
┄ 폐쇄망 경계 안에서 전부 구동 ┄
