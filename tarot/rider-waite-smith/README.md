# Rider-Waite-Smith 타로 (78장 + 뒷면)

- 그림: Pamela Colman Smith (1909, 원본 Rider 판). 퍼블릭 도메인.
- 해상도: 약 1110 x 1920 px JPG
- 이미지 출처: https://github.com/LacChe/tarot-logger (`tarotLogger/app/src/main/res/drawable-v24/`)
- 원본 파일명 매핑: atuNN=메이저, water=컵, fire=완드, air=소드, earth=펜타클, 01~10=에이스~10, 11=페이지, 12=나이트, 13=퀸, 14=킹

## 폴더 구조
- `major/00_the_fool.jpg` ~ `major/21_the_world.jpg` (22장)
- `cups/`, `wands/`, `swords/`, `pentacles/` : `<수트>_<01~14>_<랭크>.jpg` (각 14장)
- `card_back.jpg` : 카드 뒷면
- `cards.json` : 파일 경로, 영문/한글 이름, 가로/세로 픽셀 목록
